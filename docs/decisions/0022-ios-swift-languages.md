# 0022 iOS Swift 版：简体中文、繁體中文（台灣）、English 和 App 内选语言

- 状态：已采纳（`ios-swift/`）
- 日期：2026-11-08

## 背景

给台湾和说英文的朋友试用。界面原来只有写在代码里的简体中文，日期也是手写的「11月8日 周六」。
要求：默认跟随系统，「我的」里单独一项「语言」可以选；译文按当地习惯写，不要机翻腔。

## 决定

- **文字放在 String Catalog**（`Bookkeeping/Localizable.xcstrings`）：键就是代码里的简体中文原文，另有 `zh-Hant`（台湾用语）和 `en`。
  - SwiftUI 的 `Text("…")`、`Button("…")`、`Section("…")` 这类本来就按键查，代码不用改。
  - 在代码里拼出来的字符串（`String` 类型）用 `L("…")`，可以带 `\(数量)` 这类插值；账本给的中文名称（类型、状态、来源、默认分类、银行、现金和电子钱包的名字）显示时用 `.loc`。
    用户自己起的名字不在目录里，`.loc` 原样返回。
  - 目录由 `ios-swift/Localization/translations.py` 生成（`build_catalog.py`，`--check` 列出代码里还没翻译的中文）。
    同一个中文词在不同地方意思不同时，键分开，简体显示的字另写（例如通知设置的「关闭」是 Off，关闭按钮是 Close）。
  - 英文要单复数的写成复数变体（「1 card / 3 cards」）。
- **台湾用语**：帐户、明细、币别、末四码、简讯、捷径、储存、汇入汇出、期初余额、圈存、金融卡……按台湾 iOS 和银行的说法；币种名称用系统的台湾叫法（日圆、澳币）。
  银行名称台湾、香港的银行用官方名称（臺灣銀行、滙豐），英文用 `BankCatalog` 里的英文名称。
- **日期**按选的语言用系统的格式模板（简体「11月8日 周六」、台湾「11月8日 週六」、英文「Sat, Nov 8」），12 / 24 小时制跟着系统设置。
- **选语言**（`AppLanguage`）：
  - 选的值写在 App 自己的 `AppleLanguages` 里（跟随系统时删掉），和系统「设置 › REC › 语言」是同一个值，哪边改都算。下次打开 App 时系统直接按它加载，系统自己的按钮、日期选择器也跟着变。
  - 当时就换，不用重开：`L`、`.loc` 查选的语言的 `.lproj`；主包查文字时也改查它（`LanguageBundle`）；根视图设 `locale` 并按语言重建（停在哪个标签不变），UIKit 里单独放的 SwiftUI 内容也设 `locale`。
  - 选项名称用各自的文字写（简体中文、繁體中文（台灣）、English），「跟随系统」跟着现在的语言。
- **通知**：记账结果通知按选的语言写。长按通知的分类按钮由通知扩展显示，扩展不读 App 的设置：App 发通知时把翻好的分类名称和「更多大类」「返回」这些字写进通知（`NotificationPicker.labels`），以前的通知没有就用简体中文。
- **不翻译**：「开发与调试」里的页面、导出的 CSV 表头、Siri 短语、银行通知的解析规则（只认通知原文）。

## 后果

- 新加界面文字：写简体中文，在 `translations.py` 加上台湾和英文，跑一次 `build_catalog.py`；`--check` 应该只剩开发页面和文件名。
- 账本里存的还是简体中文名称，换语言不改数据，导出、导入不受影响。
- 当时换语言时，系统自己画的少数文字（例如导航栏的返回按钮）要下次打开 App 才换。
