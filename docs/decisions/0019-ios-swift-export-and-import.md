# 0019 iOS Swift 版：导出全部数据，导入时选增量或覆盖

- 状态：已采纳（`ios-swift/`）
- 日期：2026-11-04

## 背景

- 账本只在手机本地。App 靠 iLoader 自己签名安装，签名过期、重装、换手机时数据可能没了，需要能整份导出、再导回来。
- 用户要能看懂导出的东西（Numbers、Excel 打开），也要能导回来；导入时由用户选：
  - **增量**：现在的数据不变，只加没有的；
  - **覆盖**：现在的数据全部删掉，换成导入的。
- 卡面图片占空间，用户起初说不用导出；2026-11-09 改了主意（见文末修订）。

## 决定

**导出**（`BKBackend/DataExport.swift`）：一个 zip，里面一个文件夹：

- 每种数据一个 CSV：流水、账户、余额、分类、学到的分类、识别模板、汇率、待处理、原始通知、通知里的余额，给人看；
- `备份（导入用）.sqlite`：完整的数据库副本（`VACUUM INTO`，一致的快照，不用停下自动记账），导入只读它，改了 CSV 不影响导入。

导出、导入页面和 zip 里都不放说明文字（用户的要求：用了就知道）。

zip 自己写、自己读（`ZipStore`）：只存不压缩，文件名用 UTF-8，系统「文件」App 能直接解开。iOS 没有公开的解压接口，
用第三方库要另写 ADR，自己写的只有一百多行，写和读对得上，在 Linux 上也能测。代价是文件大一些，别的软件重新压缩过的读不了。

**导入**（`BKBackend/BackupImport.swift`，「我的 › 数据 › 导入数据」）：

- 先把备份升级到这个版本的表结构（`Migrations.migrate`），比 App 新的备份不能导入；之后两边的表一样，一行一行原样复制。
- 整个导入在一个写事务里，出错整体回滚，现在的数据不变。
- 导入前自动把现在的数据存一份（`导入前的数据.sqlite`，和账本在同一个目录），可以撤销上次导入；撤销就是用这份覆盖导入。
- **覆盖**：先清空每张表（有外键的先删），再把备份里的全部放进来。
- **增量**：这里有的一条不动，备份里的逐条看「这里有没有」：
  - 账户：同一个编号，或者同一家银行、同一个尾号、同一种卡（现金、电子钱包看名称；删除的不算）就是同一个。
    重装后重新添加的卡编号不同，靠这条对上，备份里这张卡的流水记到这里的那张上；
  - 分类：同一个编号、同一个系统标识，或者同一类、同一个大类下同名的就是同一个；
  - 通知：同一个编号或同一条内容（指纹）就是同一条；这里已经处理过的通知，它的待处理和余额不再加；
  - 流水：同一个编号，或者把去重键里的账户、通知编号换成这里的之后一样（同一条通知记出来的同一笔，`IngestEngine.dedupeKey`）就是同一笔；
  - 初始余额、学到的分类、识别模板、某天的汇率、设置：这里已经有的不变；
  - 配对的转帐、合成一单只剩一笔的（另一笔这里本来就有），不再算配对、合单。
- 卡面图片不在备份里：图片不在这台手机上的，清掉图片标识，卡面用颜色。

## 没有选的

- **只导出 CSV、导入时解析 CSV**：CSV 是给人看的（中文名称、格式化的金额），反过来解析容易丢信息，用户在表格里改过也会出错。
- **导出 JSON**：要给每张表写编码、解码，以后加列还要改；数据库副本加迁移天然跟着表结构走。
- **iOS 自带的压缩（`NSFileCoordinator` 按「上传」读取文件夹）**：能压不能解，导入时还要第三方库。
- **增量时按金额、时间猜是不是同一笔**：会把两笔真的一样的消费当成一笔。只认编号和去重键，宁可多一笔也不丢一笔。

## 影响

- 导出的 zip 有完整卡号和通知原文。
- 以后加表要放进 `BackupImport.tables`（有外键的排在它引用的表后面），增量时要写清楚「同一个」怎么认。

## 修订（2026-11-09）：卡面图片和设置也导出，导入时勾选

背景：付费账号改了 Bundle ID（ADR 0023），新 App 要从旧 App 导出、导入。导入后卡面变回颜色，「我的」里的设置
（外观、图标、主题色、语言、主要币种、通知、统计页选的范围）全回到默认，最新汇率（只缓存在本机设置里）也没了。
用户要「导出就是导出所有的东西，导入就是恢复到配置好的样子」，或者导入时自己勾选。

- **导出**不分选项，全部都放：zip 的文件夹里加 `卡面图片/<图片标识>.jpg`（App 存的那份，已经裁成卡片大小）和 `设置.json`
  （`AppSettingsBackup`）。BKBackend 只管放进 zip、取出来（`BackupExtras`），图片和设置由 App 读写，BKCore 仍不碰 UIKit。
- **导入**时备份里有图片或设置，就多一组勾选：账本、卡面图片、设置，默认全选。账本勾上时照旧选增量或覆盖；
  只勾图片或设置时一个「导入」按钮。图片先存好（同一个标识已经有了就不动）再导入账本，账户的卡面才认得出图片。
- **设置**导入后马上生效：语言、图标、主题色当场换；备份里打开了通知、这台手机还没给权限的，先问，不给就关掉。
  不放性能开关、开发与调试、汇率缓存：账本里有每天的汇率，启动和导入后取最近一天的（`RateDAO.latest`）。
- 以前的备份没有这两样，导入页面和以前一样。撤销上次导入只撤账本；已经存下的图片留着，没有卡面用它也不碍事。
