## D. 性能（只在真机上测，不用模拟器下结论）

打开「我的 › 性能开关与调试指标 › 显示帧率与内存」，同一操作在默认设置和单独改动一个开关后各录屏一次。

iPhone 16 Pro 上第一行应写 120 Hz（低电量模式下是 60）。长帧按两个刷新周期算：120Hz 时超过约 17ms 就算，比 60Hz 时严一倍，读数不能和之前的构建比。
最后一行是最近一次转场的读数，例如「返回 末帧跳 0.04pt · 长帧 0.02s 31ms」：末帧跳是卡片落定时最后一步跳的距离，长帧是主线程超时的时刻（转场开始后多久）和时长，最多列 3 个。
Core Animation 播放的动画不受主线程影响，长帧不一定等于动画卡了。调试指标的计时器自己会把屏幕保持在高刷，看刷新率的影响时要关掉调试指标再看一遍。
