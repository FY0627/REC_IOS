# 付款页截图（微信、支付宝）

选型见 [ADR 0021](../../decisions/0021-ios-swift-payment-screenshots.md)。代码：`Bookkeeping/Intents/RecordPaymentScreenshotIntent.swift`、`Bookkeeping/App/ScreenshotReader.swift`（Vision 识别）
→ `BKBackend/Parsing/ScreenshotParser.swift`（排成行、认页面、读字段）→ `IngestEngine`（`screenshotRoute`、`screenshotTwin`、`mergeScreenshot`）。

- 入口：快捷指令「截屏 → 记录付款截图」设到轻点背面（「我的 › 快捷指令 › 截图记账」）；「记一笔 › 从相册选截图」补记以前的。动作也接受「从图像中提取文本」的文字。
- 认的页面：付款成功页、账单详情（付款、转账、红包、退款）、聊天里点开的转账页、零钱提现和充值、微信收款商业版的收款和经营账户提现。不是付款页的截图不保存；像付款页又读不全的进待处理，可以「拷贝原文」。
- 转账页按标题看谁收的钱：「你已收款」是收到，「阿翔已收款」「待阿翔确认收款」是转给阿翔。
- 哪个 App：看页面上只有一边有的字（「零钱」「经营账户」「聊天位置」，「余额宝」「账单分类」）。都没有时，标题写着谁收款、或者同时有「转账时间」「收款时间」的是微信转账页（要对方点收款的只有微信）。
  还认不出时看「支付成功」左边、上面对勾的颜色：绿的是微信，蓝的是支付宝（`BKBackend/Parsing/ScreenshotIcon.swift`，像素在 `ScreenshotReader` 里取）。新版微信扫码付款的成功页只有「支付成功」、商家、金额、「返回商家」，靠的就是它。认出的 App 存成这条输入的发送方（「微信支付」「支付宝」）；快捷指令交过来的文字没有颜色。
  两样都认不出、两个钱包都有时进待处理选账户，通知写「微信或支付宝」。
- 商户：标签（「收款方」「商户名称」…）> 金额下面写着「名称 ¥同样的金额」的那一行，取左边的名称 > 金额上面那一行 > 金额下面不像广告的一行。
  支付宝扫码付款的成功页：金额上面只有「支付成功」和右上角的「回首页」，加上对勾常被认成同一行「• 支付成功 回首页」。这一行每段都是标题或按钮，不算商户；
  商户在金额下面（「示例科技 ¥ 0.03」）。「交易方式」也是支付方式。金额下面广告里的「红包」（「每天都可赚红包」）不算红包页。
- 经营账户：顾客付给店铺的钱记成收入（底部「退款」按钮不算退款）；提现到卡记成转帐，卡是另一边。
- 余额宝、零钱通：从银行卡转入（「余额宝-单次转入」，付款方式写的卡）记成余额宝、零钱通这边的收入，转出到银行卡记成支出；和零钱、余额之间挪钱不记。
  刚转完的完成页没有「余额宝-单次转入」，只有标题「转入成功」（和对勾、「回首页」常认成同一行，不算商户）、「开始计算收益」和付款方式：
  标题是「转入成功」「转出成功」、页面上有「收益」或「余额宝」「零钱通」的也算；写了零钱通是零钱通，否则支付宝的是余额宝、微信的是零钱通。
  卡上那笔银行通知（「支付宝-余额宝」快捷支付）先到、后到，两笔都在时合成一笔转帐（`IngestEngine.pairWithCard`），详情里能拆开。
- 名称后面的「>」「›」是箭头，不算进名称（支付宝账单详情的标题「余额宝 >」）。
- 记到哪：支付方式写了卡记到那张卡；零钱、余额或者没写记到这个 App 的钱包；零钱通、余额宝、花呗、经营账户先找名称里有它的账户（花呗找不到进待处理）。还没添加钱包的等添加后自动记上。
- 时间：页面写了交易时间按它排；成功页没写，用截图的时间。
- 和银行通知、另一张截图是同一笔时合并，补上商户（银行写的「财付通-…」换成截图上的名称）和时间；没写用什么付的截图记到了钱包、后来银行通知到了，改到那张卡上。
- 认不出的截图（一笔也没认出、或者进了待处理）先留在 App 里，「待处理 › 没认出的截图」里点出金额、卡号、对方做成截图模板，或者删掉；
  到了保留期限自动删。截图先看截图模板，再用自带的读法。见 [ADR 0028](../../decisions/0028-ios-swift-screenshot-templates.md)、[templates](templates.md)。
- 银行 App 的换汇页（众安「货币兑换成功」）：读卖出、买入的币种和金额（「卖出 (USD)  买入 (HKD)」和上一行的金额，或者「-USD 5.00」「+HKD 39.02」），记成同一个账户里的一对转帐（同卡换汇），`IngestEngine.exchangeRoute`、`pairExchange`。页面上没有银行和卡号：记到同时有这两个币种的账户，没有或有几个时进待处理选账户。
